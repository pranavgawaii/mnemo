## Sources of truth

- Backend contracts: `backend/app/models/schemas.py` and `backend/app/api/routes.py`.
- Web API reference: exported `public/openapi.json`, with notes in `lib/api/endpoints.ts`.
- Tutorial responses: `lib/api/example-responses.json`; checked against the backend schemas.
- Published benchmark: `public/benchmark-results.json`, generated by `backend/benchmark/report.py`.
- Default scoring and conflict checks: `backend/app/core/`; the frontend mirror is in `lib/memory/scoring.ts`.

The browser simulation does not call the API or reproduce MiniLM similarity.
The saved retrieval benchmark is in-sample and does not establish agent quality
or conflict accuracy. Keep these boundaries explicit when changing content.

## Maintainer reference

`internal/` contains planning notes and implementation history, separate from
the product guides. `design-reference/` archives the original design kit and is
excluded from application builds. `assets/` holds repository screenshots;
`licenses/` retains attribution for copied third-party assets.
