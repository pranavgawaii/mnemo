## Sources of truth

- Backend contracts: `backend/app/models/schemas.py` and `backend/app/api/routes.py`.
- Web API reference: exported `frontend/public/openapi.json`, with notes in `frontend/src/lib/api/endpoints.ts`.
- Tutorial responses: `frontend/src/lib/api/example-responses.json`; checked against the backend schemas.
- Published benchmark: `frontend/public/benchmark-results.json`, generated by `backend/benchmark/report.py`.
- Scoring and conflict rules: `backend/app/core/`; the browser uses the scoring adapter and generated Python rule data in `frontend/src/lib/memory/`.

The browser simulation does not call the API or reproduce MiniLM similarity.
The saved retrieval benchmark is in-sample and does not establish agent quality
or conflict accuracy. Keep these boundaries explicit when changing content.

## Repository structure

`frontend/` contains the self-contained web app, its public assets and browser
tests. `backend/` contains the API, migrations and benchmark; `sdk/` contains the
Python client. Shared contract tooling lives in `scripts/`.

`assets/` holds the shared architecture diagram, brand assets and repository screenshots; `licenses/` retains third-party notices.
Font license text ships with the web assets in `frontend/public/fonts/`.
